## 四个实测坑（别再踩）
1. **一个 `@startuml…@enduml` 只放一张图**（混着放 `-checkonly` 直接 rc=200 报 `Error line N`）；同一文件可多块，导出会切成 `_001/_002`。
2. **类图/用例图等需要 graphviz `dot`**，本机**没有** ⇒ 抛 `Cannot run program "/opt/local/bin/dot"`（语法检查不受影响，仍 rc=0）；**绕开办法＝在那块加一行 `!pragma layout smetana`**（纯 Java 布局，实测 rc=0、全部导出成功）。时序图/活动图不需要 graphviz。
3. **`-checkonly` 通过 ≠ 图好看**：布局与连线合理性要人看，别把 rc=0 当"图没问题"。
4. 中文标签没问题，但**别用全角括号混排**到 PlantUML 关键字里；标签含特殊字符要加引号。
