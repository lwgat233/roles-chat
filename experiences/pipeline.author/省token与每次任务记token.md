**症状**：交付里贴大段正文与日志回放，token 白烧；报告写成长篇、看不出是哪一步、成本只给美元。

**真因**：把对话当成交付载体（大段内容该走文件）；报告没有行数与标题纪律。

**做法（本人 2026-09-23 两次收紧；权威出处 `roles-chat/README.md`）**：
1. **报告模板（整条 ≤8 行，含标题；超了 `report()` 直接拒）**：
   `【<项目>-<步号> <步名>】<角色全名> · <HH:MM>` / `做：`（≤40 字）/ `证据：`（路径）/ `判据：`（数字 + 结论）/
   `等：`（下一步等谁，没有写"无"，未验写"未验≠通过"）/ `成本：调用 N 次 · 输入 X · 输出 Y · 缓存读 Z · ≈¥W`。
2. **先说结论再说数字**：回答短、只给结论 + 关键数字；原始输出/大段正文一律进证据文件（给路径 + 哈希前 12 位）。
3. **不重复劳动**：同一份大文件不反复整读（先看目录/段落），只在改动范围里检索；不回放日志。
4. **成本用人民币**：`≈¥W = 美元估算 × cny_per_usd`（默认 **7.2**，`talk.db` 的 `setting.cny_per_usd`）。
   取数：`~/.hermes/state.db` 的 `session_model_usage`（按 `session_id`，用
   `SELECT id FROM sessions WHERE title='<角色全名>';` 查）；**长命会话取任务前后两次读数相减**。
5. **进度通知也瘦身**：只报**刚动的那个项目**（`progress_line(project='…')`），没变的项目不列。

**判据**：① 报告 ≤8 行、标题在首行、五段齐；② 数字能从 state.db 复算（给会话 id 与两次读数）；
③ 对话里没有大段正文回放；④ 通知里只出现刚动的那个项目。
