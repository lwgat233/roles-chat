**症状**：交付里贴大段正文与日志回放，token 白烧；本人问"这次花了多少"没人答得上。

**真因**：把对话当成了交付载体（大段内容该走文件），且没人记用量。

**做法（本人 2026-09-23 定）**：
1. **回答短**：只给结论 + 关键数字；大段内容走文件（给出路径 + 哈希）。
2. **不重复劳动**：同一份大文件不反复整读（先看目录/段落），只在改动范围里检索。
3. **不回放日志**：交付里给证据路径 + 哈希，不要把原文粘进对话。
4. **报告四行之外加一行用量**：`本次任务 token：调用 N 次 · 输入 X · 输出 Y · 缓存读 Z · ≈$W`
   —— 取数：`~/.hermes/state.db` 的 `session_model_usage`（按 `session_id` 累计，会话 id 用角色名查
   `SELECT id FROM sessions WHERE title='<角色全名>';`）。**长命会话要取任务前后两次读数相减**。
5. 规格见 `roles-chat/docs/需求-周期询问与静默纪律.md` ⑦（含基线表）。

**判据**：① 交付报告里有那一行；② 数字能从 state.db 复算（给会话 id 与两次读数）；③ 对话里没有大段正文回放。
