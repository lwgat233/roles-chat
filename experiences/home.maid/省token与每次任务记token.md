**症状**：交付里贴大段正文与日志回放，token 白烧；报告写成长篇叙事，本人要翻半天；成本只给美元、看不出人民币。

**真因**：把对话当成交付载体（大段内容该走文件），且报告没有行数与格式纪律。

**做法（本人 2026-09-23 定，格式以 `roles-chat/README.md` 为准）**：
1. **报告/提交一律 ≤15 行**：一行一件事；判据只留"数字 + 结论"；原文一律进证据文件（对话里不贴路径以外的内容），不写过程叙事。
2. **回答短**：只给结论 + 关键数字；大段内容走文件（给出路径 + 哈希前 12 位）。
3. **不重复劳动**：同一份大文件不反复整读（先看目录/段落），只在改动范围里检索。
4. **不回放日志**：证据 = 路径 + 哈希，不要把原文粘进对话。
5. **报告末行给成本（人民币）**：`本次任务：调用 N 次 · 输入 X · 输出 Y · 缓存读 Z · ≈¥W`
   —— `¥ = 美元估算 × cny_per_usd`（默认 **7.2**，存在 `talk.db` 的 `setting.cny_per_usd`，本人要改就改这个键）。
   取数：`~/.hermes/state.db` 的 `session_model_usage`（按 `session_id`；会话 id 用
   `SELECT id FROM sessions WHERE title='<角色全名>';` 查）。**长命会话取任务前后两次读数相减**。
6. 规格与基线见 `roles-chat/docs/需求-周期询问与静默纪律.md` ⑦。

**判据**：① 报告 ≤15 行且四行齐全 + 末行成本行；② 数字能从 state.db 复算（给会话 id 与两次读数）；③ 对话里没有大段正文回放。
